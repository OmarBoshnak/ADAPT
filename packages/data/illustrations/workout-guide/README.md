# Workout Guide illustrations

Exercise drawings from [Workout Guide](https://github.com/bryllim/workout-guide) by
[Bryl Lim](https://bryllim.com), downloaded at commit
[`aac5992`](https://github.com/bryllim/workout-guide/tree/aac599224bb9780305239607ef98540b7e0ce389/packages/workout-guide/assets).

**Licence:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The full notice is in
[LICENSE-ASSETS](LICENSE-ASSETS), and upstream attribution in [UPSTREAM-ATTRIBUTION.md](UPSTREAM-ATTRIBUTION.md).
Per-frame records for the eleven drawings used here, copied from the upstream manifest, are in
[manifest.json](manifest.json). All 33 frames are Bryl Lim's own work; none is derived from Everkinetic.

**Changes:** none. The SVG files are stored exactly as published. At build time `tools/build-graph`
reads each frame's single path so the TV can draw it with `react-native-svg`, in the same white fill.

| Drawing | Shown for |
| --- | --- |
| `jumping-jack` | Jumping Jacks, Star Jump, and Step Jacks and Toe-Tap Jacks played more slowly |
| `high-knees` | High Knees, and High Knee March and Standing March played more slowly |
| `burpee` | Burpees |
| `squat-thrust` | Squat Thrusts |
| `half-burpee` | Step-Back Burpees |
| `skater-hop` | Skater Hops, Lateral Bound, and Skater Steps played more slowly |
| `mountain-climber` | Mountain Climbers, and Slow Mountain Climbers played more slowly |
| `bodyweight-squat` | Bodyweight Squat, and Squat to Calf Raise played more slowly |
| `jump-squat` | Freehand Jump Squat |
| `forward-lunge` | Alternating Reverse Lunges and Split Jump: the same bottom position |
| `lateral-shuffle` | Side Step Touch |

The TV credits the drawings on its Home screen. Movements no drawing here shows use ADAPT's own figures in
[../adapt](../adapt/README.md).
